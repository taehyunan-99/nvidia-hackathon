# Project Test Maker

프로젝트의 의도와 위험을 근거로 신뢰 가능한 최소 테스트 포트폴리오를 설계·생성·진단·평가하는 저장소 로컬 Codex 스킬이다.

## 사용 시점

프로젝트 전반의 테스트 전략 또는 테스트 공백을 분석하거나, 테스트와 fixture를 만들거나, 생성된 테스트를 독립 평가하거나, 로컬 검증 정책·기존 validation router 연동을 검토할 때 `project-test-maker`를 명시적으로 호출한다. 일반적인 인증 작업이나 승인되지 않은 운영 환경 테스트에는 사용하지 않는다.

## 주요 구성

- `SKILL.md`: 모드 선택, 신뢰성 기준, 안전 규칙 및 결과 형식
- `references/`: 테스트 전략, criticality, 채점, 로컬 실행·이관 지침
- `scripts/`: rubric 컴파일, 생성 테스트 채점, 로컬 validation 보조 도구
- `agents/openai.yaml`: 에이전트 메타데이터

## 의존성 및 설정

별도 전역 Codex 스킬 설치는 필요하지 않다. 스크립트는 이 폴더를 기준으로 실행하며, 생성물·실행 산출물은 스킬 폴더가 아닌 대상 프로젝트의 Git 디렉터리 아래 `project-test-maker/runs/<run-id>` 또는 격리된 임시 경로에 둔다. 실제 테스트 실행에 필요한 언어 런타임과 프로젝트 의존성은 대상 프로젝트의 지침을 따른다.
