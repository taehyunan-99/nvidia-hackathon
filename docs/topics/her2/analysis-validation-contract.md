# 실제 모델과 구조 분석 검증안

2026-09-27. 상태: **거부 반복 수정·실모델 내부 검증 통과, 사용자 직접 E2E 대기**. 현재 인계의 첫 단계인 분석 계약 검토 결과다. 2026-09-27 사용자가 이 기준에 따라 구현→실모델 검증→로컬 사이트 실행을 승인했다. 구현 완료나 현재 E2E 준비 완료를 뜻하지 않는다. [검증 기준](validation.md), [PRD](../../PRD.md)의 F03·F05–F10과 Q05를 따른다.

## 권장 완료 범위

확보한 구조에서 계산할 수 있는 충돌·표면·예측 자세 차이를 검증한다. 전체 당쇄·막·미관측 원자가 없어 계산할 수 없는 전체 접근성은 값 없이 이유와 필요한 자료를 표시한다. 이 제한을 사용자가 데모 완료 기준으로 수락한 경우에만 해당 보류를 유지한 채 사용자 E2E로 진행한다. 전체 접근성 검증 완료, 후보의 결합력·효능·안전성, 새 항체 예측 정확도는 주장하지 않는다.

기존 인계는 전체 접근성의 미완료를 E2E 차단사항으로 두었다. 따라서 단순히 표시 문구를 바꾸거나 단위 검사가 통과했다는 이유로 이 관문을 통과시키지 않는다. 범위 결정은 사용자, 구현과 독립 검산은 분석 작업 담당이 맡는다.

MolProbity의 심각한 비결합 겹침 기준은 약 0.4 Å이며 clashscore는 전체 원자 1,000개당 해당 충돌 수다. 이것을 단순 중원자 거리 검사에 적용하거나 항체의 생물학적 부적합 임계값으로 쓰지 않는다. 원자 유형·수소결합 처리는 원도구를 따른다. 도구의 설치·라이선스·현재 mmCIF 사슬 대응과 Docker 실행 가능성은 구현 전 확인할 사항이다.

## 최소 실제 호출 계획

- 입력: 승인된 1N8Z/1S78의 HER2 607잔기와 전체 Fab를 사용한 구조 재사용 실행 1건. 예측 실행은 기존 `service.demo_input.prediction_demo()`의 공개 참조 1후보+가상 중쇄 변이 1후보, 1건으로 한정한다. 가상 변이는 배선 검증용이며 실재 항체나 독립 정확도 평가셋으로 표시하지 않는다.
- 예측: 기존 Boltz-2 endpoint, recycling 3·sampling 50·diffusion samples 2, 성공 응답 1건 목표. 실패 재시도를 포함한 실제 HTTP 요청 최대 4건. 이미 응답받은 예측을 정확도 개선 목적으로 반복하지 않는다.
- 판단: NAT의 위 두 실행 합계에서 실제 Nemotron HTTP 요청 최대 40건. 기본 반복 횟수만으로 물리 요청 수가 보장되지는 않으므로 실행 전에 요청 단위 상한을 강제하고 계수한다. 부가 규칙 판단이 모델을 부르는 경우도 같은 상한에 포함한다.
- 시간·중단: 실행당 기존 1,200초, 동시 실제 분석 1건. 인증/결제 오류, 입력·반환 서열 불일치, 호출 상한 도달 시 중단한다. 계정 증액·유료 자원 생성 없이 기존 계정을 사용하며, 반복 실행은 실패 원인과 남은 예산을 검토한 뒤 별도로 정한다.
- 증거: 입력·설정·요청 시각·응답 상태·재시도 수·모델/규칙 주체·선택 전 각 구조·해시·파일 대응·실패 이유. 키·쿠키를 공유 문서와 로그에 넣지 않는다. 현재 모델 목록 조회 1회는 추론 요청과 별도로 기록했다.

이 호출 한도는 제공자의 무료 한도나 비용 보증이 아니라 이번 검증의 자체 상한이다. 모델 목록에 ID가 있다는 사실로 추론 성공을 예고하지 않는다.

### 실행 중 확인한 오류와 제한된 재검증

첫 공개 구조 실행은 실제 NAT로 완료했다. 첫 예측 실행은 Nemotron의 `finish_reason=length`로 도구 호출 전에 응답이 잘렸고, 규칙 복구가 실제 Boltz-2의 두 구조를 계산했다. 이 실행을 NAT 전체 성공으로 집계하지 않는다. [공식 모델 카드](https://build.nvidia.com/nvidia/nemotron-3-super-120b-a12b/modelcard)의 `enable_thinking=false`를 명시하도록 수정하고 전송 검사 12건을 통과했다. 출력 한도 1,024토큰은 유지한다.

재검증은 예측 정확도 개선 실험이 아니라 이 전송 오류의 수정 확인이다. 기존 합계 상한(Nemotron 40·Boltz-2 4)을 유지한 채 예측 경로를 한 번 다시 확인하고, 최신 설정의 공개 구조 경로는 브라우저에서 확인한다. 실패한 최초 기록과 규칙 복구 표시를 보존한다. 더 많은 표본을 생성해 유리한 예측을 고르는 실험은 수행하지 않는다.

## E2E 진입 관문

1. 사용자가 위 관측 범위와 전체 접근성 보류를 데모 완료 기준으로 확정한다.
2. 정식 충돌과 복수 자세 계산을 구현하고 독립 기하·공식 도구 대조, 결측·잘못된 대응·실패 회귀를 통과한다. 구현하지 못한 필수 계산을 미확인 표시만으로 완료 처리하지 않는다.
3. 실제 모델의 재사용/예측 두 경로와 화면·보고·개별 구조의 출처를 검증한다. 같은 최신 이미지에서 격리 DB·권한·재시작·복원·삭제를 확인한다.
4. 그 뒤 별도 로컬 Compose와 새 DB/볼륨으로 사이트를 실행하고 사용자에게 주소를 제공한다. 기존 서비스·DB·개인 env는 보존한다. 공개 배포는 별도 요청이다.

현재 사이트는 `http://127.0.0.1:18095`, Compose project는 `her2-user-e2e`다. 사용자가 다른 worktree에서 소개·팀 페이지를 작업하는 동안 웹/API는 종료하지 않고 유지했다. 소개·팀 파일은 수정하지 않았다. 실행이 없는 worker만 교체했으며, 화면 자산은 서버를 중단하지 않고 교체했다. `.env.local-e2e`는 개인 설정이고 키를 포함하므로 Git에 넣지 않는다. 검증용 공유 호출 계수는 보존하고 이후 사용자 직접 실행에는 기본 실행별 상한을 적용한다. 별도 worktree의 수정은 이 Docker 화면에 자동 반영되지 않는다.

**이 시점에는 사용자 전체 E2E 준비 완료 판정을 보류했다.** 아래 후속 수정·재검증 이전에는 예측 경로의 모델 단독 완주 문제가 남아 있었다. 실제 사용자 테스트·공개 배포·새 항체의 과학적 정확도는 완료로 기록하지 않는다.

## 도구 거부 반복 수정과 최종 내부 검증

실제 NAT 그래프에 대역 모델 응답만 넣어 거부→교정과 같은 거부 반복을 재현했다. 거부 메시지는 모델에 전달되지만 기존 요청은 모든 도구와 자유 형식 인자를 계속 허용했다. 이전 실패에서 모든 원본 인자가 저장되지는 않았으므로 당시 거부의 구체적인 인자를 추정하지 않는다.

`CandidateTools.model_tool_schemas`와 `PacedNIM`에서 현재 상태의 허용 도구만 노출하고, 이유는 검증한 설명의 enum으로, 의견은 현재 근거 상태에서 허용되는 enum으로 제한했다. 종료 전 도구 선택을 요구하며 같은 도구의 동일 거부가 연속 두 번이면 다음 외부 요청 전에 중단한다. 기존 실행 관문·숫자 검사·실패 시 규칙 복구 표시는 유지한다. 모델이 여러 유효 행동 중 선택하는 역할과 계산/판정의 코드 책임을 바꾸지 않는다. [기존 B 전환 방향과 구현](nat-agent-loop.md#2026-09-27-상태별-도구인자-노출-적용)을 따른다.

- 실제 NAT 그래프의 거부 후 교정·정상 종료, 동일 거부의 조기 중단, 공유 스키마 보존을 검사했다. 모델/예측 응답을 바꾼 검사와 실제 외부 호출을 구분한다.
- 남은 승인 1회로 실제 Nemotron이 예측 도구와 제공된 이유를 선택하고 기존 인자 검사를 통과함을 확인했다. 이때 Boltz는 실행하지 않았다.
- 사용자가 전체 검증용 Nemotron 최대 8회를 추가 승인했다. 기존 52회를 이어받아 합계 상한 60회로 확인했고, Boltz 상한 4회는 유지했다.
- 새 영속 실행 `run-5248a6a9092142e9ac8c3fdb5a451eaa`에서 공개 구조 1후보와 가상 변이 1후보가 **실제 모델로 종료**했다. 약 113.1초, 도구 거부 0건·에이전트 오류 0건·규칙 복구 0건. 실제 Boltz 응답 2샘플의 검증·정렬·충돌·저장·JSON/CSV·파일 해시·세션 격리까지 통과했다.
- 최종 제품 검사 **320 passed, 2 skipped**. 생략한 opt-in 실호출 검사와 별도로 위 실제 영속 실행을 검증했다. 전체 통과 수를 실모델 검사 수로 바꾸지 않는다. 테스트 DB만 정리했고 웹/API의 실행 시작 시각이 유지되는 것을 확인했다.

최종 검증 사용량은 Nemotron **60/60**, Boltz-2 **4/4**다. 추가 자동 추론은 하지 않는다. 검증용 공유 계수는 보존하고, 사용자 직접 실행에 소진된 공유 계수가 적용되지 않도록 개인 환경 설정은 실행별 기본 한도로 돌린다. 웹/API는 유지하고 작업이 없는 worker만 교체한다.
