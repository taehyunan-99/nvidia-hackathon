# A-03 예측 입력 적합성 검토

기준: 2026-09-26, 저장소 `bc040999b2df06291758c54140307e920a5b9ce4`. [승인 입력](a01-reference-inputs.md)의 두 Fab·HER2 UniProt 23–629와 [관측 당 비교](a03-glycan-context.md)를 유지한 후속 검토다. **서열 발췌본 검토는 완료했으나 실제 예측 구조 계산은 보류한다.** 전체 좌표·실제 요청·호출 근거가 현재 checkout에서 발견되지 않았고, 발췌본 중쇄는 승인된 원본과 다르다.

## 1. 자료 가용성과 확인 수준

현재 checkout 전체에서 ignored 파일을 포함해 구조 확장자 `.cif/.mmcif/.pdb`, B가 저장하는 `boltz2_response.json`, `call_log.jsonl`, 이름에 request가 포함된 JSON을 조사했다. `.git`, `.venv`, `node_modules`, `__pycache__`는 제외했고 순회 오류는 없었다. 다른 checkout·기기·외부 저장소는 조사하지 않았다. 임의 이름의 JSON·압축 파일 내부까지 검사한 결과는 아니다.

| 자료 | 로컬 확인 | 의미와 부족한 부분 |
|---|---|---|
| A-01 입력·기탁 서열·공개 구조 | 있음 | 승인 범위와 서열을 독립 대조할 기준. 실제 예측 요청 그 자체는 아님 |
| [예측 발췌 fixture](../../../logic/tests/fixtures/boltz2-response-excerpt.cif) | 2,982 bytes, polymer 3개, `_struct_asym` A/B/C | `_atom_site`가 전혀 없어 좌표·접촉·SASA·정렬 검증 불가 |
| 전체 예측 좌표 | 발견되지 않음 | 발견된 구조 8개 중 7개는 A-01 공개 구조 및 프런트 복사본, 나머지 1개는 위 fixture |
| 전체 요청 및 호출별 설정 | 발견되지 않음 | 입력 역할·후보 ID·실제 전송 서열·범위·모델 설정·실행 ID를 연결할 근거 필요 |
| 응답 JSON·호출 로그 | B의 저장 파일명으로 발견되지 않음 | 반환 신뢰도, 실행 시각·성공 상태, 원본과 추출 좌표의 대응을 직접 확인하지 못함 |

자료 보존 구현도 확인했다. [NVIDIA client](../../../logic/nvidia_client.py)의 요청 로그는 서열 대신 ID·길이·설정 요약을 저장한다. `boltz2_response.json`도 `_without_structures`로 구조 문자열을 길이 표시로 바꾸므로 파일명만으로 전체 원본이라 판단하면 안 된다. [Flow](../../../logic/flow.py)의 `_record_predicted`는 첫 구조를 별도 CIF에 저장한다. 전체 전송 payload와 각 응답 구조·신뢰도·호출 ID를 묶은 자료를 받아야 요청–응답 대응을 입증할 수 있다.

|---|---:|---|---|

## 3. 사슬·잔기 대응 및 누락 기준

요청 A/H/L과 반환 A/B/C의 이름을 직접 연결하지 않는다. 실제 전송 서열 → `_entity_poly` → `_struct_asym.entity_id` → `_atom_site.label_asym_id`를 전체 문자열과 원자 행으로 확인해야 한다. fixture에는 첫 두 종류의 메타데이터만 있어 원자 행까지 연결됐다고 볼 수 없다.

B의 `_predicted_chain_mapping`은 서열로 첫 strand를 선택하고 같은 서열이 여러 번 나오면 첫 대응을 유지한다. 따라서 중복 서열·여러 사슬·동일 복사체의 유일성 검증을 별도로 요구한다. 현재 예제의 서열 대응 성공을 일반적인 복사체 구분 성공으로 확대하지 않는다.

[계약](../../frontend-hosting/contracts/service.schema.json)의 `Chain`, `Residue`, `Structure`, `Evidence`를 유지한다. author 사슬·번호가 없으면 null을 유지하며, label 번호나 요청 ID를 author 번호로 채우지 않는다. 각 모델·사슬에서 label 위치, 잔기 종류, 좌표 유무, 삽입 코드, 입력 서열 위치를 대조한다. 표적의 1–607이 정확히 P04626 23–629라는 조건이 확인되면 입력 서열 위치에서 UniProt 위치로 +22 대응이 가능하지만, atom label 번호 자체에 이 오프셋을 무조건 적용하지 않는다. 항체는 각 요청 사슬의 전체 서열 위치를 기준으로 한다.

예측 자료의 잔기 누락·부분 원자·대체 좌표·점유율·모델 수를 별도 목록화한다. author 번호 null은 좌표 부재와 다르다. 원자가 없다는 이유로 누락을 측정된 0으로 처리하지 않으며, 당 좌표가 없는 예측을 실제 당이 없는 환경으로 해석하지 않는다.

추가 입력 경계: A-01 `review-input.json`은 전체 HER2 FASTA와 분석 범위를 별도로 보존하지만, 현재 B `_predict`는 전달받은 target FASTA 전체를 정규화해 보낸다. 분석 범위가 실제 요청 전에 어떻게 적용됐는지 원본 payload로 확인해야 한다. fixture의 607잔기만으로 모든 입력 경로에서 범위 처리가 검증됐다고 할 수 없다. B 코드는 이번 작업에서 수정하지 않았다.

## 4. 후속 계산 전에 적용할 검증 사례

다음 표는 **후속 구현의 기대값**이며, 전체 좌표가 필요한 검사를 이번에 실행했다는 뜻이 아니다. 이번에 직접 확인한 것은 파일 목록·해시·좌표 블록 부재·서열 전체 비교·독립 파서 일치다.

| 사례 | 독립 기대값 / 처리 |
|---|---|
| 정상 요청–응답 | 각 역할의 전송 서열과 반환 entity가 완전히 일치하고 유일하게 대응. 모델·좌표·파일 해시·실행 ID가 같은 호출을 가리킴 |
| 요청 사슬 재명명 | A/H/L → A/B/C라도 서열과 entity/atom 대응으로 역할 유지. 이름만 같은 사슬 선택 금지 |
| 같은 길이의 서열 불일치 | 현재 중쇄 사례는 31번 D→A 한 곳으로 검출. 길이 226 일치만으로 통과 금지; 원본 후보 계산 보류 |
| 중복 서열·복사체 | 첫 사슬 자동 선택을 정답으로 간주하지 않음. 복사체·모델·대응 근거가 없으면 보류 |
| 좌표 없음·일부 잔기 누락 | 현재 fixture는 전체 좌표 없음으로 계산 `not_run`, 값 null. 부분 누락은 원래 입력 위치에 표시하고 사용한 부분 범위와 영향 명시 |
| author 번호 없음 | label/서열 대응이 확인돼도 author 값은 null 유지. 화면 강조·출력 대응에서도 번호를 발명하지 않음 |
| 접촉 | 작은 합성 좌표에서 임계거리 아래·경계·위의 원자 쌍을 직접 거리 계산으로 대조. 선택 규칙·중원자·경계 포함 여부를 고정하고 잔기 집합 전체를 비교 |
| 표면 노출·당 조건 | 단일 구 및 두 구의 독립 해석 기대값과 비교. 동일 단백질 좌표·원자 집합에서만 조건 차이 산출; 당 미제공은 0이 아닌 unknown |
| 정렬·자세 | 알려진 회전·이동을 준 합성 좌표의 역변환과 RMSD를 대조. 같은 표적 잔기를 정렬한 뒤 항체 자세 비교; 대응 잔기 부족·공선 등 퇴화 조건은 보류 |
| 단일 예측·신뢰도 누락 | 단일 결과로 예측 간 자세 일관성 산출 금지. 없는 신뢰도는 null 및 사유. 추가 샘플의 설정·독립성 근거를 먼저 요구 |

예측 좌표로 계산한 수치는 `computed` 근거이며, 구조의 `kind=predicted`를 유지한다. `measured`는 좌표에서 수치를 계산했다는 상태이지 실험 결합력이나 치료 효능의 증거가 아니다. 정식 충돌 기준·효능 임계값은 이 검토로 확정하지 않는다.

## 5. 다음 실행 조건과 인계

**지금 가능:** 승인 입력과 fixture의 서열·범위 비교, 누락 자료 목록·검증 기준 인계. **보류:** 실제 예측 좌표의 접촉·SASA·정렬·당 비교와 예측 간 자세 일관성, 화면·서비스 통합 검증.

B로부터 받을 자료는 다음과 같다. 이 문서는 요청 목록이며 메시지 전송이나 추가 API 실행은 하지 않았다.

1. 해당 호출의 전체 전송 payload: 후보/실행 ID, 실제 표적·중쇄·경쇄 서열, 분석 구간과 설정, 모델/endpoint·시각. 인증키는 제외한다.
2. 응답 메타데이터와 모든 원본 구조 파일, 구조별 신뢰도·샘플 인덱스, 요청–응답–파일의 해시 대응 및 호출 성공 근거. 구조 문자열이 제거된 JSON에는 별도 CIF를 반드시 연결한다.
3. 중쇄 D31A 후보의 의도·후보 ID와 분석 범위 확인. 기존 두 Fab 검증이라면 승인된 원본 서열에 맞는 자료가 필요하다. 변이 후보라면 사용자 확인 전 범위를 확장하지 않는다.

자료 수령 뒤 파일·서열·사슬·잔기 대응 검증을 통과한 계산만 시작한다. 현재 공개 구조 전용 A-02/A-03 계산기를 그대로 예측 파일에 적용하지 않는다. 이번 입력 검토 단계는 완료이며, 실제 예측 분석의 준비 완료를 뜻하지 않는다.
