# A-03 관측 당 포함 조건 비교

기준: 2026-09-26. [A-01 승인 입력](a01-reference-inputs.md)과 [A-02 단백질 계산](a02-structure-metrics.md)을 유지한 제한된 A-03 단계다. 두 공개 구조의 assembly 1, HER2 UniProt 23–629와 전체 기탁 Fab를 사용한다. 예측 구조·정식 충돌 판정·실제 B/서비스 연결은 이 단계의 완료 범위가 아니다.

## 관측 당과 원본 근거

| 구조 | 포함한 당의 label 사슬 / author 번호 | 관측 중원자 | 원본 공유결합 주석 |
|---|---|---|---|
| 1N8Z | D / 766, E / 738 | 28 | HER2 author ASN 165→D 766, ASN 237→E 738 |
| 1S78 | G / 1·2, H / 1·2, L / 1006 | 70 | HER2 author ASN 165→G 1, ASN 237→H 1, ASN 508→L 1006; G 1→2, H 1→2 |

모두 원본 `_chem_comp.type`이 saccharide인 NAG다. 위 ASN 숫자는 author 번호이며 UniProt 위치로 직접 사용하지 않는다. 원본 사슬·label/auth 번호·삽입 코드와 전체 서열 위치의 대응을 결과에 따로 보존한다. 1S78 원본에 BMA 정의가 있어도 assembly 1에 그 좌표가 없으므로 포함하지 않는다. assembly 2의 당·단백질을 섞지 않는다.

좌표는 A-01의 assembly 파일을 사용한다. `_struct_conn` 공유결합 주석은 원본 ASU 파일에서 읽어 assembly 1의 양 끝 원자와 실제로 대응시킨다. 주석의 거리와 관측 좌표의 거리를 검증하며, 주석 없는 연결을 거리만으로 새로 추정하지 않는다. 원본 파일·해시는 [A-01 source-lock](assets/a01/source-lock.json), 구체적 당·결합 대응은 [당 목록](assets/a03/generated/glycan-inventory.json)에 있다.

당의 `label_seq_id`와 `sequence_position`은 null이다. 특히 G·H 사슬 각각의 두 당을 `(model, label 사슬, author 사슬, author 번호, 삽입 코드, 성분)`으로 구별한다. 표면 계산 라이브러리에 필요한 내부 임시 번호는 출력 잔기 번호로 내보내지 않는다.

## 계산 정의

| 조건·지표 | 정의 |
|---|---|
| core | A-02와 동일한 관측 HER2·Fab 중원자만 배치 |
| context | 동일한 단백질 원자·좌표에 assembly 1의 관측 NAG 중원자를 가림 요소로 추가 |
| 단백질 표면 노출 | 두 조건 모두 **단백질 원자만**의 용매 접근 표면적(SASA)을 합산. 당 자체의 표면적은 합산하지 않음 |
| 표면 감소량 | `core 단백질 SASA − context 단백질 SASA`, 단위 Å². 양수는 관측 당 때문에 줄어든 계산상 단백질 노출 |
| 해상도 차이 | 960점과 1920점에서 계산한 감소량의 절대 차이. 과학적 판정 임계값이나 신뢰구간이 아님 |

Biopython Shrake–Rupley, probe 1.4 Å, 원자당 960/1920점, A-02의 C/N/O/S 반지름을 그대로 사용한다. 동일 단백질 좌표의 fingerprint를 기록하고, 각 해상도의 core 총면적을 저장된 A-02 총면적과 대조한다. 잔기별·표적/중쇄/경쇄별 결과를 함께 제공한다. 공유결합된 당도 가림 요소에 포함하며 결합 주변을 임의로 빼지 않는다. 단백질 재배치나 에너지 최소화는 하지 않는다.

## 제외·누락·해석 경계

- 물·황산 이온·수소/중수소·막은 제외한다. 다른 당 성분, 미지원 원소, 대체 좌표, 부분/0 점유율, 잘못된 연결 대응은 명시적 오류로 처리한다.
- 관측 당이 없는 입력의 비교는 `unknown`과 null이다. 관측 당이 있지만 단백질에서 충분히 멀어 가리지 않는 경우에만 측정된 0이 가능하다.
- 관측된 NAG는 전체 생리적 당쇄가 아니다. 빠진 당과 원자를 복원하지 않으며, 일부 당의 좌표가 있다는 사실로 당의 완전성을 선언하지 않는다.
- A-02의 단백질 잔기 누락과 부분 원자 누락을 그대로 전달한다. 1N8Z HER2 26잔기와 Lys 원자 12개, 1S78 HER2 52잔기·중쇄 4잔기의 누락은 계산으로 없어지지 않는다.
- 감소량은 관측 구조·조건의 기하학적 비교다. 항체의 실제 접근 가능성, 결합력·효능 순위, 세포 환경의 전체 표면이나 충돌 없음으로 해석하지 않는다. `whole_range_accessibility=unknown`, `atom_clash=not_run`을 유지한다.

## 실행 결과

두 구조 모두 같은 해상도의 core 계산이 A-02 기준 총면적과 일치했다. 단위는 Å²이며, 아래 총면적은 HER2와 Fab를 합친 **단백질만의 면적**이다.

| 구조 | 960점 core | 960점 context | 960점 감소량 | 1920점 감소량 | 감소량의 해상도 차이 |
|---|---:|---:|---:|---:|---:|
| 1N8Z | 47,482.8768 | 47,242.1520 | 240.7248 | 240.9628 | 0.2380 |
| 1S78 | 46,188.2676 | 45,761.9361 | 426.3314 | 429.4694 | 3.1380 |

관측된 감소는 두 해상도 모두 HER2에 나타났고 Fab 중쇄·경쇄 감소량은 0이었다. 이는 이 좌표와 제한된 당 성분의 결과이며, 완전한 당쇄가 항체를 가리지 않는다는 증거가 아니다. 1S78의 감소량이 더 크다는 사실도 후보 우열을 뜻하지 않는다. Windows/Python 3.12.10 환경에서 첫 전체 계산은 약 249초였으며 서비스 응답 시간이나 최대 자원 사용 보장은 아니다.

## 검증과 인계

[검사 코드](assets/a03/test_compare.py)는 한 구의 표면적과 두 구의 교차로 생기는 구면 모자의 해석식, 먼 당의 측정된 0, 당 자료가 없는 경우의 unknown을 확인한다. 실제 입력에서는 당 identity·공유결합·assembly 범위, 원래 단백질 보존, A-02 값과의 일치, 잔기 합계, 누락 보존, 계약 및 전체 결과의 byte 재생성을 검사한다. 실행 기록은 [validation.json](assets/a03/generated/validation.json), 계산 설정과 값은 [summary.json](assets/a03/generated/summary.json), 파일 해시는 [provenance.json](assets/a03/generated/provenance.json)을 따른다.

실행 결과: **15개 검사 통과**, 실패·오류 0개. 원본부터 전체 결과를 재생성해 JSON/CSV byte 일치를 확인했고, 입력·구현·산출물 해시와 A-02 기준값도 확인했다. 실행 시간만 달라지는 provenance와 검사 기록 자체는 byte 재현 비교에서 제외한다.

로직 B는 [실행·연결 안내](assets/a03/README.md)의 Condition/Evidence 추가분을 기존 A-02 자료와 연결한다. 별도 서비스 계약 변경이나 실제 운영 연결 성공을 전제하지 않는다. 예측 구조를 받았을 때의 자세 일관성 분석은 A-03의 남은 별도 단계다.
