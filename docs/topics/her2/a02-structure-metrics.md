# A-02 첫 공개 구조 계산

기준: 2026-09-26, A-01 `a01-2`, 각 assembly 1, HER2 UniProt 23–629 및 승인된 전체 Fab 구간.
이 문서는 첫 로컬 계산의 재현 조건이다. Q05의 후보 판정 임계값이나 결합력·효능 판단을 확정하지 않는다.

## 계산 계약

| 항목 | 이번 정의 | 해석 경계 |
|---|---|---|
| 접촉 | 표적과 Fab의 관측 중원자 사이 거리 ≤4.5 Å. 원자 쌍, 잔기 쌍, 표적/항체/합계의 고유 잔기 수를 따로 기록 | 기존 화면·B의 근접 선택과 비교하기 위한 계산 설정. 결합력 점수 아님 |
| 충돌 참고값 | 두 단백질 사이 최소 중원자 거리 및 `max(0, max(r_i+r_j-distance))` | 원소별 반지름을 쓴 기하학적 겹침. 수소·수소결합·원자 유형별 반지름을 고려한 MolProbity clashscore가 아님. `atom_clash` 판정은 `not_run` 유지 |
| 표면 노출 | Biopython Shrake–Rupley SASA, probe 1.4 Å, 원자당 960점 및 1920점 비교, Å² | 선택된 관측 단백질 원자만의 용매 접근 표면. 누락 잔기·미관측 원자·전체 당쇄·막의 영향 미포함 |
| 결합면 매몰 | 같은 좌표에서 SASA(표적 단독)+SASA(Fab 단독)−SASA(복합체). 양쪽 감소량의 합이며 2로 나누지 않음 | 결합 전 구조를 예측한 값이 아니며 자유에너지·친화도 아님 |
| 정렬 | 공통 UniProt 위치 중 양쪽에 관측된 HER2 Cα를 모두 사용해 1S78→1N8Z 최소제곱 강체 정렬 | 영역별 유연성·도메인 운동을 섞은 전역 RMSD. 항체 자세 정확도나 결합력 점수 아님 |

Biopython 1.88의 원소별 반지름 중 C=1.70, N=1.55, O=1.52, S=1.80 Å를 명시적으로 사용한다. 다른 원소는 기본 반지름을 임의 적용하지 않고 거부한다. 거리 기준·반지름·probe·표면 점수는 산출물에 저장한다.

## 포함·제외·번호·누락

- A-01 원본 해시와 서열·잔기 대응을 확인한다. 계산할 잔기는 전체 입력의 `sequence_position`과 승인 구간으로 고른다. 구조 label 번호에 전체 FASTA 번호를 직접 대입하지 않는다.
- model 1·assembly 1의 표적/중쇄/경쇄만 포함한다. 수소·중수소·물·이온·관측 당은 이번 단백질 중심 계산에서 제외하고 개수를 기록한다. 원본 파일이나 전체 대응표에서는 삭제하지 않는다. 당 포함 조건 비교는 A-03이다.
- 좌표 없는 잔기는 대응표와 누락 목록에 유지한다. 잔기의 원자가 존재한다는 것과 모든 원자가 관측됐다는 것은 다르며, 부분 원자 누락도 완전한 구조로 해석하지 않는다.
- 1N8Z에는 경쇄 A:190, 중쇄 B:30·B:217의 Lys 측쇄 원자 CG·CD·CE·NZ, 총 12개의 미관측 주석이 있다. 해당 잔기는 `has_coordinates=true`지만 원자 수준에서는 불완전하다. 원본 주석과 전체 잔기 identity를 `summary.json`의 `missing_atom_annotations`에 보존하고 조건의 자료 공백에도 표시한다. 1S78에 같은 범주의 주석이 없다는 사실은 미주석 원자까지 완전하다는 증거가 아니다.
- 좌표 누락·0 점유율·대체 위치·미지원 원소·입력 불일치를 확인한다. 이번 고정 구조에 없는 애매한 경우를 임의 보간·선택하지 않고 실패시킨다.
- 계산값은 관측 범위에 한정한다. 전체 구간의 완전한 접촉·충돌 없음·접근성 판단은 자료 부족으로 보류한다. 값 0과 미실행/null은 구분한다.
- label/auth 번호와 삽입 코드, model, assembly/operator, 전체 FASTA 위치를 보존한다. 비단백질의 null 서열 위치를 좌표 누락으로 오해하지 않는다.
- 정렬은 행 우선 4×4 행렬을 열벡터에 곱하는 서비스 계약으로 변환한다. 원본 파일에 적용하지 않으며 `applied=false`다. 화면이 적용할 때 딱 한 번만 적용한다.

## 구현 전에 정한 검증 기준

1. 접촉: 손으로 거리를 정한 합성 좌표에서 경계 포함(4.5 Å), 경계 밖, 중복 잔기, 빈 좌표를 확인한다. 공개 구조에서는 별도 이웃 검색과 기존 `contacts.json`의 잔기 집합을 비교한다. 기존 파일 일치는 호환성 검사이지 과학적 정답의 전부가 아니다.
2. 표면적: 독립적으로 유도한 단일 구 `4π(r+probe)²`, 서로 떨어진 두 구의 합, 두 구 교차 시 구면 모자 면적과 비교한다. 공개 구조에서 960/1920점 결과 차이를 수치 오차 자료로 남기며 임의의 과학적 합격 임계값을 붙이지 않는다.
3. 정렬: 비공면 합성 좌표에 알려진 회전·이동을 적용한 사례에서 원좌표 복구, 행렬 방향·직렬화, 강체 거리 보존을 확인한다. 부족하거나 퇴화한 기준점은 거부한다.
4. 누락: 1N8Z HER2 26개, 1S78 assembly 1 HER2 52개(승인 구간 안)·중쇄 4개가 유지되는지 확인한다. 누락 위치는 접촉 잔기나 정렬 기준점으로 들어가면 안 된다. 1N8Z의 부분 원자 누락 12개도 잔기 좌표 유무와 구분해 보존하고 보간하지 않는다.
5. 계약: Structure·Alignment·Condition·Evidence·Artifact 스키마, 파일 해시·후보/조건/구조 참조, source→잔기 번호를 대조한다. 이는 실제 서비스/화면 통합 성공을 뜻하지 않는다.

## 근거

- [기존 근접 선택](../../frontend-hosting/assets/3d-research/build-contacts.py), [로직 B 접촉 계산](../../../logic/contacts.py): 4.5 Å와 중원자·양쪽 잔기 선택의 현재 저장소 근거. 과학적 후보 판정값으로 승인된 수치가 아니다.
- [Biopython SASA 공식 문서](https://biopython.org/docs/latest/api/Bio.PDB.SASA.html): Shrake–Rupley, probe·점수·반지름 설정. 현재 설치된 1.88 구현의 반지름을 확인했다.
- [FreeSASA 기하학 설명](https://freesasa.github.io/doxygen/Geometry.html): 원자 반지름에 probe를 더한 구의 노출 표면이라는 SASA 정의. 이번 실행은 FreeSASA 실행 검증이 아니다.
- [Biopython SVD 정렬 공식 문서](https://biopython.org/docs/latest/api/Bio.SVDSuperimposer.html): 최소제곱 정렬과 행벡터 오른쪽 곱 규약. 서비스 계약의 열벡터 규약으로 변환해야 한다.
- [MolProbity 원저자 설명](https://onlinelibrary.wiley.com/iucr/itc/Fb/ch21o6v0001/sec21o6o2o2/): 수소결합 등 처리와 비결합 원자 겹침에 근거한 clashscore. 단순 중원자 겹침에 이 명칭·판정을 붙이지 않는다.
- [승인 입력과 누락 처리](a01-reference-inputs.md), [서비스 정렬 계약](../../frontend-hosting/temporary-contract.md): 이번 계산의 범위·번호·행렬 의미.

## 결과와 후속 연결

2026-09-26 로컬 CPU 계산 결과다. 비교 가능한 관측 원자에 한정한 기술 지표이며 수치가 큰 후보가 더 좋다는 뜻이 아니다.

| 항목 | 1N8Z · trastuzumab | 1S78 · pertuzumab |
|---|---:|---:|
| 접촉 잔기 합계 | 39 | 56 |
| 표적 / 항체 접촉 잔기 | 19 / 20 | 26 / 30 |
| 접촉 원자 쌍 / 잔기 쌍 | 221 / 42 | 325 / 57 |
| 관측 단백질 복합체 SASA (960점), Å² | 47,482.88 | 46,188.27 |
| 양쪽 매몰 SASA 합 (960점), Å² | 1,444.08 | 2,121.43 |
| 960→1920점 매몰 SASA 차이 (1920점 값 대비) | 0.0436% | 0.0135% |
| 최소 표적–항체 중원자 거리, Å | 2.417 | 2.581 |
| 최대 원소 반지름 겹침 참고값, Å | 0.653 | 0.489 |
| 승인 구간의 좌표 없는 잔기 | HER2 26 | HER2 52, 중쇄 4 |

공통 HER2 Cα 548개를 이용한 1S78→1N8Z 정렬 RMSD는 **1.3598 Å**다. 누락 잔기는 기준점에 넣지 않았으며, 원본 좌표는 변경하지 않았다.
표면 점수를 두 배로 늘렸을 때 차이가 작다는 것은 이 입력의 수치 적분 확인이다. 반지름 선택·미관측 원자·당쇄 누락 등에 의한 과학적 불확실성까지 작다는 뜻은 아니다.
원소별 겹침 값에는 수소결합 등 가까운 접촉이 포함될 수 있으므로 값이 0보다 크다고 충돌이라고 판정하지 않는다.

검증 결과: **18개 검사 통과**. 손으로 유도한 구의 표면적·합성 거리·알려진 강체 변환, 별도 이웃 검색과 기존 접촉 집합 대조, 전체 잔기/부분 원자 누락, 잘못된 대응·해시·후보 참조의 거부, 서비스 계약 조각 및 오프라인 전체 재생성을 포함한다. 검사 이름과 결과는 [검증 기록](assets/a02/generated/validation.json)에 있다. 원본 6개는 해시가 유지됐고, `docs/plan.md`와 기존 B·서비스·화면 코드는 이번 작업에서 변경하지 않았다.

계산·검증 산출물은 [A-02 재현 안내](assets/a02/README.md)에서 찾는다. 상세 원자·잔기 목록은 파일로 저장하고 요약만 표시한다.
현재 B의 실험 구조 경로는 화면의 정적 `contacts.json`을 읽고 `residue_mapping=[]`, `alignment=null`을 만든다. 이번 A-02는 해당 빈칸에 사용할 계약 조각과 계산 근거를 제공한다. 서비스 DB·worker·화면의 실제 소비와 예측 구조 확장은 별도 통합 검증이다.
