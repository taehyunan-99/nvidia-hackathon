# HER2 에이전트의 판단 흐름과 도구

기능 목적·입력·산출물은 [프로젝트 개요](overview.md), 완료 확인은 [검증 기준](validation.md)을 따른다.
아래는 구현할 흐름이며 실제 실행 결과가 아니다.

## 에이전트와 직접 구현할 부분

원문 설계의 구성은 **[Nemotron 3 Nano](https://build.nvidia.com/nvidia/nemotron-3-nano-30b-a3b) + [NeMo Agent Toolkit(NAT)](https://github.com/NVIDIA/NeMo-Agent-Toolkit)**다.
Nemotron은 상태에 따른 작업 선택과 결과 설명을, NAT는 함수 연결·실행 흐름·추적을 맡는 구성으로 설계한다.
실제 모델 제공 상태·계정 접근·호환 버전은 구현 전에 확인한다. 애플리케이션의 프런트엔드·서버·배포 스택은 아직 정하지 않았다.

NVIDIA 스킬은 실행 절차의 참고자료다. 자료 조회, 입력 검증, 번호 대응, 표면·접촉 계산, 예측 호출, 후보 비교와 보고서 생성 함수는 직접 연결·구현해야 한다.

## 단계별 상태 → 판단 → 실행 → 결과

| 단계 | 확인할 상태와 판단 | 실행 도구·기능 | 결과와 다음 행동 |
|---|---|---|---|
| 1. 입력·자료 대응 | HER2와 항체 후보의 서열·형식·분석 구간이 구조와 맞는가? | UniProt REST, RCSB PDB Search/Data API, Thera-SAbDab, Biopython | 서열·사슬·잔기 번호 대응표와 누락 구간을 남긴다. 불일치하면 비교 전 정정한다. |
| 2. 결합 부위 검토 | 실험으로 알려진 접촉과 계산상 부위를 구분할 수 있는가? | Biopython, FreeSASA; 추가 근거가 필요한 경우 선택적 IEDB Query API | 접촉 부위·표면 노출·근거를 정리한다. 필요한 구조가 없으면 해당 판단을 보류한다. |
| 3. 필요한 복합체 예측 | 실험 구조·기존 결과로 충분한가? 새 예측이 필요한가? | 필요할 때 MSA-Search NIM → Boltz-2 NIM | HER2 분석 구간과 항체 사슬의 복합체 mmCIF·신뢰도를 확보한다. 불안정한 결과는 제한된 재실행 또는 보류한다. |
| 4. 후보별 구조 비교 | 입력 오류·충돌·다른 예측 자세·당쇄 또는 주변 구조가 판단을 바꾸는가? | Biopython의 NeighborSearch·Superimposer, NumPy, 직접 작성할 검사 함수 | 접촉 잔기, 표면 노출, 충돌, 구조 정렬과 자세 일관성을 비교한다. 지표가 충돌하면 각각의 이유를 남긴다. |
| 5. 결과 제시 | 어느 부분까지 근거가 있고 어떤 질문이 남는가? | Mol*, NAT 실행 추적, JSON/CSV 결과 저장 | 3D 비교, 후보별 근거표, 검토 의견·보류 이유, 후속 확인 목록과 출처를 연결한다. |

## 단계가 고정 파이프라인이 되지 않게 할 분기

- 일치하는 공개 실험 구조로 충분하면 불필요한 복합체 예측을 생략한다.
- 서열·사슬·잔기 번호가 맞지 않으면 그 후보의 비교를 먼저 보류한다.
- 당쇄·인접 영역이 누락됐다면 해당 구조가 없다고 결론내리지 않고 자료 보완 또는 접근성 판단 보류로 연결한다.
- 예측 결과가 불안정하면 조건을 기록하고 재실행 또는 보류한다. 횟수·시간 한도는 구현 전에 정한다.
- 신뢰도 값이 높아도 충돌이나 입력 오류를 통과시키지 않는다. 지표를 근거 없는 종합 점수로 합치지 않는다.
- API 실패·timeout을 성공한 분석으로 표시하지 않는다. 실패 단계와 아직 생성하지 못한 결과를 구분한다.

## 같은 후보에서 비교할 구조 조건

| 조건 | 비교 내용 | 해석 경계 |
|---|---|---|
| HER2–항체 중심 | 접촉 위치·방향, 표면 노출과 원자 간 충돌 | 확보한 구조에서의 결합 가설 |
| 확보한 당쇄·주변 구조 포함 | 추가되는 공간적 간섭과 기존 자세의 유지 여부 | 해당 구조 조건에서의 접근성 |
| 관련 자료 부족 | 누락 구간, 당쇄 좌표·조성, 인접 구조의 정보 공백 | 불확실한 항목을 남기고 그 판단은 보류 |

당쇄의 영향을 단순한 입체 차폐 하나로 설명하지 않는다. 위암 세포에서의 ErbB2 당쇄와 trastuzumab 민감도를 다룬 연구도 구조 그림만으로 모든 생물학적 반응을 설명하는 근거는 아니다. [Duarte et al., 2021](https://pubmed.ncbi.nlm.nih.gov/33947960/)

## 도구 선택과 구현 미정 항목

[HER2 도구 문서](../../tools/her2-toolkit.md)는 도구별 사용 조건과 원출처를 관리한다.
함수명·API 스키마·접촉 거리·충돌 기준·구조 정렬 구간·예측 통과 점수·재실행 한도는 아직 구현 계약으로 확정하지 않는다.
필요한 결정을 먼저 확인하고, 테스트 기대값을 구현 결과에서 그대로 만들어내지 않는다.
