# 신청용 에이전트의 준비 수준을 어떻게 잡을까?

> 이전 기록: `nvidia/docs/15-demo-readiness.md`에서 2026-09-24 이관. 아래 조사·작성 기준일을 유지하며 이번 이관에서 외부 사실이나 실행 결과를 재검증하지 않았습니다.

기준일: 2026-09-22. **공식 확인은 에이전트 데모 제출까지이며, 아래 기준은 조사 결과에 따른 제안이다.**
영상 길이·저장소 공개·필수 파일 등은 [공식 신청서](https://docs.google.com/forms/d/e/1FAIpQLScyZ5GYYaCOycNUzXVUTenliEUmSEIdXelVdYphvMvLeLuiHA/viewform) 확인 전 확정할 수 없다.

## 권장하는 최소 완료 흐름 — 분석

1. 사용자가 목표와 입력 데이터를 제공한다.
2. 에이전트가 입력에 따라 필요한 작업을 선택한다.
3. 모델이 하나 이상의 실제 도구를 호출한다.
4. 반환값을 보고 추가 호출·오류 대응·완료 여부를 판단한다.
5. 결과물과 근거 또는 검증 결과를 함께 제시한다.

도구 1개라도 목표에 맞게 선택·실행·검증하는 흐름은 의미가 있다.
여러 에이전트·학습·복잡한 UI는 공개 안내에서 필수로 확인되지 않았다.
NVIDIA API나 스킬 사용을 요구하는 미션의 세부 조건은 별도로 충족해야 한다.

## 완성도 단계 — 공식 기준 아님

| 단계 | 관찰 가능한 상태 | 판단 |
|---|---|---|
| 환경 확인 | 모델 API가 텍스트를 반환 | 연결 확인 수준 |
| 기능 확인 | 실제 도구를 호출하고 결과 반환 | 구성요소 동작 확인 |
| 작은 에이전트 | 목표→선택→실행→검증→완료 | 제출 준비의 기술적 기준 후보 |
| 재현 가능한 데모 | 새 입력·실패 입력에서도 동작, 로그·실행 방법 존재 | 설명과 검토가 쉬운 상태 |
| 운영 서비스 | 권한·부하·장기 운영·복구·서비스 품질 | 예선 데모와 별도 범위 |

## 보여줄 증거 — 분석

| 증거 | 확인할 내용 |
|---|---|
| 입력과 목표 | 무엇을 성공으로 정의했는가 |
| NVIDIA 사용 지점 | 실제 모델 ID·도구·스킬 역할 |
| 도구 실행 기록 | 도구명·인자 요약·반환 상태·시간 |
| 결과 산출물 | 근거 있는 답, 파일, 계획표, 영상 구간 등 |
| 검증 | 원문 인용, 수치 일치, 제약 위반 없음 등 |
| 재현 방법 | 의존성·환경 변수 이름·데이터·실행 순서 |
| 한계 | 미구현 기능·실패 조건·데이터 범위 |

내부 chain-of-thought를 공개할 필요는 없다. 작업 단계 요약과 실제 도구·결과 기록으로 충분히 설명할 수 있다.

## 작은 검증 세트 제안 — 분석

- 정상 입력: 목표를 끝까지 수행하는 대표 사례.
- 변화 입력: 질문·수치·문서가 바뀌어도 고정 답변을 내지 않는지 확인.
- 정보 부족: 필요한 값을 묻거나 불확실성을 표시하는지 확인.
- 불가능한 입력: 없는 문서·모순된 제약·모델 timeout을 성공으로 처리하지 않는지 확인.
- 반복 실행: 비슷한 품질·시간에 완료하는지 확인.

예를 들어 10~20개 사례는 초기 오류를 찾는 작은 표본이 될 수 있다. 이 수는 대회 요구나 통계적 신뢰성 기준이 아니다.
평가 시 입력, 기대 결과, 실제 결과, 성공 판정, 도구 호출 수, 완료 시간을 함께 기록한다.
RAG는 `rag-eval`, workflow는 NAT 평가 등을 활용할 수 있다. [NAT 평가](https://docs.nvidia.com/nemo/agent-toolkit/latest/workflows/evaluate.html)

## 지금 준비할 수 있는 것과 다음 결정

**지금:** 스택 이해, 데이터 확보 가능성 조사, 모델/API 접근 조건 확인, 기술 후보별 자원 비교.
**신청서 확인 후:** 필수 NVIDIA 구성·제출 형식·미션을 반영한 범위 결정.
**주제 결정 후:** 가장 작은 실행 경로 구현→실패 사례 보완→재현 가능한 데모 준비.
**본선 준비:** 당일 공개 미션을 예상해 과도하게 특정 문제에 고정하지 않고, 익힌 도구를 재사용할 수 있도록 구조와 실행법을 이해한다.

이번 조사에서 설치·키 발급·GPU 임대·모델 실행·신청 제출은 수행하지 않았다.
