# 참가 신청 폼 전체 분석

> 이전 기록: `nvidia/docs/23-application-form-snapshot.md`에서 2026-09-24 이관. 아래 조사·작성 기준일을 유지하며 이번 이관에서 외부 사실이나 실행 결과를 재검증하지 않았습니다.

`nvidia2`에서 옮긴 **2026-09-20 공개 폼 스냅샷**이다. 신청·제출 전 실제 폼과 운영진 안내를 재확인한다. 이 문서는 신청 완료나 운영진의 규정 답변을 증명하지 않는다.

조사일: 2026-09-20 · 출처: [공식 Google Form](https://docs.google.com/forms/d/e/1FAIpQLScyZ5GYYaCOycNUzXVUTenliEUmSEIdXelVdYphvMvLeLuiHA/viewform).

Aside에서 폼 첫 화면을 읽고, 같은 브라우저의 페이지 소스에 포함된 공개 질문 정의를 확인했다. 동의 항목 선택, 개인정보 입력, 업로드, 신청서 제출은 하지 않았다. 아래 필수 여부는 공개 폼 정의의 설정값이며 제출 직전에 실제 화면을 다시 확인해야 한다. 파일 개수·용량 제한은 이 조사에서 확정하지 못했다.

## 신청 흐름

안내 및 개인정보 수집·이용 확인 → Section 01 개인정보·팀 정보 → 팀장이면 Section 02 서비스 제출 → Section 03 제3자 제공·일정·마케팅 동의 선택 → 제출.

팀원은 서비스 제출 섹션을 건너뛴다. 앞부분 설명에는 개인정보 입력 후 설문이 종료된다고 적혀 있지만, 공개 분기 설정은 팀원을 Section 03으로 이동시킨다. 따라서 팀원도 마지막 동의·일정 확인 화면이 나오는지 확인해야 한다.

## 첫 화면

행사 개요, 전체 일정, 지원 자격, 교육 미션 링크, Build 링크, 예선 평가 기준, 신청 방법, 문의처를 안내한다. ‘지원서 작성 전 확인’은 필수 응답이며 개인정보 수집·이용에 동의해야 지원할 수 있다고 설명한다.

## Section 01 — 팀장·팀원 공통

| 질문 | 형태 / 필수 | 준비할 정보와 해석 |
|---|---|---|
| 참가 팀 이름 | 단답 / 필수 | 팀원 모두 공백까지 동일하게 입력. 중복되지 않는 팀명 권장 |
| 팀 구성 인원 | 단일 선택 / 필수 | 2명, 3명, 4명, 5명 |
| 이름 | 서술 / 필수 | 연락·심사 안내에 사용할 이름 |
| 연락처(휴대폰 번호) | 서술 / 필수 | 하이픈 포함 `010-0000-0000` 형태 |
| 이메일 주소(NVIDIA 계정 아이디) | 서술 / **설정상 선택** | 안내상 NVIDIA 계정 확인에 사용하므로 준비해야 함. Developer 사이트의 Account → My profile → Email 확인 |
| 직무 정보 | 복수 선택 / 필수 | 프론트엔드, 백엔드, 디자이너, PM/PO, 마케터, 창업가/대표, 기타. 현재 직무와 수행 가능한 직무 모두 선택 가능 |
| 만 19세 이상 성인 확인 | 단일 선택 / 필수 | 아래 연령 문구 불일치 참고 |
| 팀장 / 팀원 | 단일 선택 / 필수 | 팀장에게만 포트폴리오 섹션 표시 |

### 나이 조건은 확인이 필요하다

질문은 ‘만 19세 이상’ 및 ‘2006년생 이전 출생자’를 제시하고, 설명은 2006년생부터 가능하며 2007년 이후 출생자는 지원할 수 없다고 적고 있다. 2026년 실제 만 나이 기준과 출생연도 문구가 완전히 일치하지 않는다. 특히 2007년생 중 생일이 지난 팀원이 있더라도 임의로 지원 가능하다고 판단하지 말고 운영진에 확인해야 한다. 폼은 미성년자가 포함되면 팀 전체가 무효 처리될 수 있다고 안내한다.

### 개인정보 안내와 실제 질문의 차이

수집 항목 설명에 Github ID가 있지만 공개 질문 목록에는 별도의 Github ID 입력 항목이 없다. 프로젝트 리포지토리 URL과 개인 Github ID를 같은 제출 항목으로 간주하지 않는다. 휴대폰 안내에는 ‘세미나 접속 URL’ 문구가 섞여 있으나 별도 세미나 개최를 확정하는 근거로 쓰지 않는다.

## Section 02 — 팀장만 작성하는 서비스 제출

| 질문 | 필수 | 준비 내용 |
|---|---|---|
| 서비스 명 | 예 | 프로젝트 이름 |
| 서비스 파일 또는 배포 URL | 예, **파일 업로드** | 아래 제출 방식에 따라 파일 준비 |
| 해결하려던 문제(Problem Definition) | 예 | 300자 내외. 사용자, 문제, 불편, 개발 동기 |
| 서비스 소개 및 주요 기능(Solution) | 예 | 500자 내외. 구현 기능, 핵심 로직, 사용자 흐름 |
| 핵심 기술 및 AI 모델(Tech Stack) | 예 | NVIDIA 모델·라이브러리·프레임워크와 전체 기술 스택을 구체적으로 기재 |
| 추가 제출 URL | 선택 | 데모 영상, 배포 서비스, 추가 기술 문서 등에 사용 가능. 구체적인 링크 종류는 폼이 제한하지 않음 |

### 가장 놓치기 쉬운 제출 방식

‘서비스 파일 또는 배포 URL’이라는 제목이지만 실제 질문은 URL 입력칸이 아닌 파일 업로드다. GitHub나 배포 링크로 제출하려면 **프로젝트명과 URL을 Word 또는 PDF 문서에 적어 업로드**하도록 안내한다. 파일 자체를 제출하는 경우 형식 제한이 없다는 문구도 있다.

지정 파일명은 `[NVIDIA 해커톤_팀명_프로젝트명]`이다. 대괄호가 실제 파일명에 포함되어야 하는지 별도 설명은 없으므로 제출 전 안내를 재확인한다. 링크가 있다는 이유로 선택 항목에만 URL을 넣고 필수 업로드를 생략하지 않는다.

**팀 준비 제안:** 업로드 문서에 프로젝트명, 문제·해결 요약, 실행 URL, GitHub URL, 시작 방법, NVIDIA 기술이 실제 동작하는 위치, 데모 영상 URL을 정리한다. 이 추가 구성은 공식 지정 양식이 아닌 심사 편의를 위한 제안이다. 비공개 리포지토리 열람 방식은 폼에 설명이 없으므로 별도 확인이 필요하다.

## Section 03 — 동의와 전체 일정 확인

| 항목 | 응답 설정 | 안내 내용 |
|---|---|---|
| 개인정보 제3자 제공 | 응답 필수, 동의/비동의 선택 | NVIDIA Korea에 성명·연락처·NVIDIA 계정 이메일 제공. 등록 대상자 확인 목적. 2026-11-30 파기. 거부하면 참여 불가라고 안내 |
| 전체 일정 확인 | 필수 | 예선 마감, 본선 발표·행사, AI Day Seoul 일정 확인 |
| 2차 마케팅 활용 동의 | **응답 필수지만 동의 자체는 선택** | 동의/비동의 선택. 거부해도 이벤트 참여·경품 지급 제한 없다고 명시 |

마케팅 동의는 리뷰 게시물 등을 패스트캠퍼스·NVIDIA의 홈페이지, SNS, 외부 커머스 등 마케팅 채널에서 가공해 활용하는 내용이며 기간은 수집일부터 1년이다. 응답이 필수인 항목과 동의해야 참가 가능한 항목을 구분해야 한다.

## 개인정보 수집·보관 안내

패스트캠퍼스는 참가 확인, 자격 검토, 팀 구성, 행사 운영, 리워드 지급 등을 위해 이름·전화번호·NVIDIA 계정 이메일·Github ID·포트폴리오 등 지원 정보를 수집한다고 안내한다. 일반 지원자는 접수일부터 6개월 이내 파기, 수상자는 수상작 발표 후 2년 보관이다. NVIDIA Korea에 대한 제3자 제공 기간과는 별개다.

Google Form은 파일 업로드 및 제출 시 Google 계정의 이름·이메일·사진이 기록된다고 안내한다. 현재 로그인된 개인 계정 정보는 이 문서에 저장하지 않았다.

## 제출 준비 체크

- 팀명·인원·팀장 지정과 팀원별 신청 완료 상태를 한곳에서 관리한다.
- 300자 내외 문제 정의, 500자 내외 해결 설명, 구체적인 NVIDIA 기술 목록을 먼저 합의한다.
- 링크 포함 제출 파일과 실제 데모 접근·실행 방법을 외부 심사자 관점에서 점검한다.
- 공개 범위·라이선스·마감 시각·파일 용량 등 미확정 조건은 운영진 답변을 받아 반영한다.
- 신청 완료 화면이나 확인 메일 등 제출 증빙을 각자 보관한다. 이 조사는 실제 신청을 수행한 것이 아니다.
