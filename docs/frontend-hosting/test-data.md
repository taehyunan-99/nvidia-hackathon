# 사이트 테스트 데이터

확인일: 2026-09-27. 목적은 준비된 실제 항체 데이터로 실험 복합체 재사용·필요 예측·계산 보류를 구분해 시연하는 것이다. “전체 기능”은 현재 연결된 분석 기능이며 MSA 연결은 포함하지 않는다.

## 선택 가능한 시나리오

| 시나리오 | 후보 | 기대 경로 |
|---|---|---|
| 실험 구조 비교 | Trastuzumab·1N8Z + Pertuzumab·1S78 | 일치하는 실험 복합체 재사용, Boltz 생략 |
| 실험 구조와 예측 비교 | Trastuzumab·1N8Z + Trastuzumab Fab D185A·6BHZ | 1N8Z 실험 구조와 6BHZ 서열 기반 HER2 복합체 예측 비교. 실제 검증 통과 후 기본값 적용 |
| 예측과 계산 보류 확인 | 위 두 후보 + Fab37·3N85 | 예측 경로를 유지하면서 Fab37 실험 좌표의 계산 보류 이유 확인 |

이는 도구 선택의 기대 경로다. NAT가 실제로 실험 구조를 선택했는지, 예측이 실행됐는지, 어떤 계산이 보류됐는지는 각 실행의 도구 기록·근거 상태로 확인한다. 후보 `completed`가 모든 계산의 성공을 뜻하지 않는다. 합성 변이 `prediction_demo()`와 오류 입력은 개발 검사로 보존하며 첫 화면의 실제 후보와 혼동하지 않는다.

## 원본과 입력 대응

[RCSB 1N8Z](https://www.rcsb.org/structure/1N8Z), [1S78](https://www.rcsb.org/structure/1S78), [6BHZ](https://www.rcsb.org/structure/6BHZ), [3N85](https://www.rcsb.org/structure/3N85)의 mmCIF를 다시 받아 `_entity_poly.pdbx_seq_one_letter_code_can`을 대조했다. 좌표에 빠진 잔기를 기탁 서열에서 삭제하거나 서열을 추정하지 않았다.

| PDB | 중쇄 entity / 잔기 수 | 경쇄 entity / 잔기 수 | 출처의 의미 |
|---|---|---|---|
| 1N8Z | 2 / 220 | 1 / 214 | HER2–Trastuzumab 실험 복합체 |
| 1S78 | 3 / 226 | 2 / 214 | HER2–Pertuzumab 실험 복합체 |
| 6BHZ | 1 / 225 | 2 / 214 | Trastuzumab Fab D185A 항체 단독 실험 구조, HER2 없음 |
| 3N85 | 3 / 224 | 2 / 217 | HER2–Fab37 실험 복합체 |

공통 표적은 1N8Z entity 3의 607잔기이며 [UniProt P04626 FASTA](https://rest.uniprot.org/uniprotkb/P04626.fasta)의 23–629 구간과 정확히 일치했다. 이미 잘린 FASTA이므로 표적 `analysis_range=null`; 후보 형식은 Fab, 중쇄·경쇄 범위도 null이다. 1S78·3N85의 624잔기 표적에서는 이 입력에 대응하는 구간만 계산하며 원본 파일은 보존한다. 1S78의 복제 사슬 선택은 기존 검증 카탈로그의 HER2 A·중쇄 D·경쇄 C를 유지한다.

6BHZ와 1N8Z의 경쇄 차이는 185번 D→A 하나지만, 중쇄는 6BHZ 말단에 `KSCDK` 5잔기가 추가되어 있다. 결과 차이를 D185A 하나의 효과로 단정하지 않는다. 6BHZ의 항체 복사체 좌표는 복합체로 선택하지 않는다.

전체 6BHZ 경쇄의 RCSB identity cutoff 1.0 검색을 재실행한 결과는 6BHZ·6BI2였다. 두 entry의 전체 H/L 기탁 서열은 일치하며 다른 polymer/HER2는 없었다. 이 제한된 검색 결과는 모든 공개 자료에 HER2 복합체가 없다는 증명이 아니다.

3N85는 선택한 표적·H/L 구간의 occupancy 0.50 원자 행 56개와 대체 좌표를 갖는다. 첫 계산 보류 사유는 부분 점유율·대체 좌표의 원자 선택이다. BMA·FUC 존재를 이 실행의 첫 보류 사유로 바꾸지 않는다.

## 생성·검증 경로

- [기존 입력](fixtures/public-reference-input.json), [예측 입력](fixtures/public-prediction-input.json), [계산 보류 입력](fixtures/public-hold-input.json)은 `service.demo_input`의 `public_reference_demo`, `public_prediction_demo`, `public_hold_demo`와 일치한다. 고유 example_id를 보존하고 결과·예상 수치를 입력에 넣지 않는다.
- 6BHZ·3N85 서열·원본 SHA-256은 [demo_sequences.json](../../service/demo_sequences.json)에 있다. 고정 원본은 [시나리오 검사 자료](../../service/tests/fixtures/scenario-sources/)에 보존한다. 검사에서 원본 해시·entity 서열·배포 JSON·분석 분기를 대조한다. 실제 실행에서는 공식 출처를 다시 조회하고 실행별 캐시 해시와 대응을 확인한다.
- 첫 화면은 가로 카드 3개로 시나리오를 선택하며 선택 상태·후보 수·실행 성격을 표시한다. 좁은 화면에서는 카드 영역을 가로로 스크롤한다. 선택은 같은 `/api/reviews`→`/runs`→결과 경로로 전달한다. 별도 동기 API에도 같은 이름의 preset을 제공한다. `DATA_MODE=mock`은 모의임을 표시하고 실제 분석으로 주장하지 않는다. 직접 입력은 기본 두 후보에서 2–4개로 추가·제거할 수 있으며 전환 중 작성 내용을 보존한다.
- `uv run --locked pytest service/tests/test_demo_scenarios.py logic/tests/test_structure_sources.py -q`는 외부 모델 없이 원본 대응·항체 단독/표적 불일치·보류 분기를 검사한다. 저장·권한 DB 검사는 별도 폐기용 PostgreSQL에서만 실행한다.

## 분석과 해석 경계

항체 단독 출처는 H/L 전체 서열이 각각 유일하게 일치하고 **그 외 polymer가 없을 때만** 서열 근거로 인정한다. 다른 표적·미일치 사슬·모호한 entity·조회 실패는 이 분기로 넘기지 않는다. 알려진 표적이 있는 부모 항체 출처의 부분 일치는 기존 규칙에 따라 후보 복합체와 구분한다. 6BHZ ID 특례는 없다.

유효한 좌표에서 접촉, 단백질 표면 노출·매몰 면적, Reduce/Probe의 정식 충돌, 예측 신뢰도와 두 예측 자세 차이를 확인한다. 도구나 원자 선택이 부적합하면 해당 항목은 not_run/unknown과 null로 남긴다. 3N85는 실험 구조를 보존하지만 접촉·표면·충돌 계산을 보류한다.

WT의 관측 당 포함/제외 비교는 확보한 좌표 범위에 한정한다. 당이 없는 예측 후보의 당 영향·당 조건과 모든 후보의 전체 접근성은 unknown이다. 예측 신뢰도·자세 일치나 계산값은 결합력·치료 효능·새 항체 정확도 증거가 아니다. [정식 분석 계약](../topics/her2/analysis-validation-contract.md)을 따른다.

## MSA 현재 상태

MSA는 현재 미연결이며 기본 실행에서 제외하고 추가 검증 후 도입을 검토한다. NAT는 고정된 Boltz-2 스킬·검증 문서를 프롬프트에 넣지만 MSA-Search 실행 도구나 간접 경로는 없다. Boltz에 HER2·중쇄·경쇄 서열을 보내며 별도 생성 MSA는 전달하지 않는다. 제공자 내부 동작까지 이 기록으로 단정하지 않는다.

[저장 예측 재채점](../topics/her2/assets/goldset/generated/saved-predictions-score.json)은 MSA 없음: 표적 접촉 5/19·F1 0.333, MSA 있음: 0/19·F1 0이다. 조건별 3개 기록은 동일 SHA-256이라 독립 3회로 세지 않는다. [성능 검증의 요청 사슬 순서 차이](../topics/her2/agent-performance-validation.md) 때문에 완전히 통제된 일반 성능 비교가 아니다. 해당 입력에서 추가 MSA의 이득이 확인되지 않았다는 범위로 해석하며, 다른 실제 후보에서 입력·순서·설정을 통제한 비교로 필요성과 개선을 확인할 때 도입을 검토한다. 원본 실험·실패 기록과 고정 NVIDIA 스킬은 보존한다.

## 이번 검증 상태

두 신규 시나리오가 별도 영속 서버에서 실제 NAT·Boltz로 완료되어 **실험 구조와 예측 비교**를 기본값으로 전환했다. 기존 실험 구조 비교도 선택 가능하다.

| 실행 | 확인 결과 |
|---|---|
| `run-9870de6a04a3448eae6bf5c0e61c550d` | 브라우저 버튼으로 접수한 WT + D185A. 약 128.7초. WT 실험 구조 1개·D185A 예측 2개, 두 예측 모두 607/225/214잔기 완전 대응. 도구 거부 0·규칙 복구 0 |
| `run-df9e7b65abee4cad8cca32f5da46471e` | WT + D185A + Fab37. 약 220.8초. WT·Fab37 실험 구조 선택, D185A 예측 2개. Fab37 접촉·표면·매몰·충돌은 not_run/null, 당 포함 표면·당 영향은 unknown/null. 도구 거부 0·규칙 복구 0 |

첫 실행의 D185A는 접촉 48잔기, 단백질 SASA 48,503.31 Å², 양쪽 매몰 면적 합 1,970.43 Å², 표적–항체 충돌 23쌍, 신뢰도 0.8541, 예측 간 항체 Cα RMSD 4.3143 Å였다. 접촉은 표적과 항체 잔기의 합이며 이 수치는 이번 산출물 설명이지 다음 실행의 고정 정답·정확도 합격선이 아니다. WT의 관측 당 표면 감소량은 240.72 Å²였다. 예측 후보의 당 조건·전체 접근성은 unknown을 유지했다.

두 실행의 D185A 예측 파일 쌍은 같은 SHA-256(`2c8db98c…f25c9`, `b11b5a72…55de`)이므로 독립된 정확도 표본 4개로 세지 않는다. 두 샘플의 3D는 개별 표시하며, 자세 비교 수치는 표적 정렬 계산값이다. 현재 화면에 구조 중첩·정렬 비교 조작이 구현됐다는 뜻은 아니다.

원본·검색 재확인, 배포 입력·분기 검사 40건, 격리 PostgreSQL의 제품 검사 326건 통과·3건 생략(실호출 opt-in 2건·로컬 Probe 조건 1건). 생략했던 공식 Probe 검사는 경로를 지정해 별도 1건 통과했다. 프런트 10건, 타입/빌드와 최종 Docker 이미지 빌드, 계약 정상 9개·오류 9개 통과. 실호출 opt-in 생략을 위 실제 영속 실행으로 구분해 보완했다.

직접 입력은 최신 요청에 따라 2–4개로 복원했고 브라우저에서 2→3→4→3→2 추가·제거, 네 개 상한·두 개 하한, 입력 방식 전환 중 이름·후보 수 보존을 확인했다. 최신 웹 이미지 빌드·반영을 통과했으며 모델은 추가 호출하지 않았다.

브라우저에서 첫 화면 세 선택지·후보 내용·기본 선택, 예측 3D와 두 구조 개별 표시, 보고서, JSON/CSV와 구조 다운로드, 새로고침 후 같은 실행 복원을 확인했다. JSON은 저장 결과와 동일하고 예측 두 파일의 전체 입력 서열·해시·크기도 일치했다. 세 후보 실행은 재접속 결과·보고서·파일 해시·익명 401·타 세션 404를 검사했다. API 재시작과 새 DB/파일 볼륨 복원 후 두 결과 JSON 및 7개 구조 파일의 무결성도 확인했다.

새 승인 한도 Nemotron 60회·Boltz-2 4회 중 **24회·2회 사용** 후 자동 실호출을 종료했다. 이전 소진 계수와 분리했으며 남은 양을 무조건 사용하지 않는다. 개인 증거는 `tmp/scenario-validation/`의 원본 검색 기록, 두 실행 원응답/결과, 검사 로그, 저장·복원 대조에 보존한다. 기존 가상 변이 성공을 이번 성공으로 대체하지 않았다. 사용자 최종 E2E 피드백·공개 배포·새 항체 정확도 검증은 별도다.

## 이전 공개 두 후보 검증 기록

최신 카드 입력·영속 저장·네 후보 직접 입력과 표시·문서 잔재 검증은 [최근 변경 후 점검](runtime-audit.md#2026-09-27-최근-변경-후-점검)을 따른다. 제품 330건·프런트 12건 통과와 저장 예측 재계산을 확인했으며 새 모델 호출은 하지 않았다. 아래는 이전 실행 기록이다.

- 자동 검사: 입력 관련 5개 통과. 서비스·로직 검사 첫 실행 163개 통과·2개 외부 호출 검사 생략, 새 저장 입력 검사의 응답 필드 오류 1개 수정 후 해당 파일 6개 통과·1개 외부 예측 검사 생략. 계약 9개 시나리오·9개 오류 변형, 프런트 빌드 통과.
- 별도 폐기용 PostgreSQL과 로컬 API·worker에서 브라우저 버튼으로 NAT 실행 `run-377387c1cadc492f860693d4d8554b4a`를 접수했다. Nemotron의 두 후보 실험 구조 선택·의견을 확인했고, 두 후보 완료·접촉 39/56·구조 2건·한계·후속 질문이 저장되었다. Boltz-2 예측은 생략했다. 실제 모델 의견은 이번 실행에서 둘 다 후속 실험 검토 가능이며, 고정 정답으로 저장하지 않는다.
- 브라우저의 직접 입력 전환·입력값 보존·JSON 업로드 제거·결과 비교·보고·재접속 복원을 확인했다. 390px에서 가로 넘침이 없고 후보 카드가 세로로 배치되는 것을 확인했다. 라이트·다크, 키보드·마우스 전환을 점검하고 기본 뷰포트·라이트로 복원했다.
