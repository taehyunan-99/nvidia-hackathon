# 프런트 디자인 기준

2026-09-25. 사용자 확인: 딱딱한 화면 대신 직관적이고 심플하면서도 트렌디한 화려함을 원하며, 밝은 배경·큰 타이포·3D 중심 구성·은은한 청록과 블루 그라데이션 제안에 동의했다. 후속 요청으로 NVIDIA 공식 디자인 시스템을 조사하고 테마에 반영했다. [조사·적용 근거](nvidia-design-research.md)를 따른다.

## 시각 기준

Calm Clarity의 4px 간격 체계와 카드·입력·버튼 구조를 사용한다. 사용자가 지정한 NVIDIA 한국 홈페이지를 시각 기준으로 삼으며 한글 SUIT Variable·영문 Arial을 대체 조합으로 사용한다. 토큰은 [프런트 토큰](../../frontend/src/tokens.css)에 보관하며 레이아웃은 [스타일](../../frontend/src/style.css), 최신 색상·폰트 조정은 [NVIDIA 참고 테마](../../frontend/src/nvidia-theme.css)에 둔다. 개인 스킬 자체는 변경하지 않는다.

- 중립 회색 배경, 흰 패널, 넓은 여백. 강조는 시작 동작과 선택 상태에 집중한다.
- 소개에는 큰 제목과 추상 입체 그래픽을 사용한다. 실제 분자 구조가 아니라는 설명을 붙이며 결과 화면의 3D를 대신하지 않는다.
- 본문 16px, 보조 설명 13px. 제목은 가이드의 22/28/36/48px를 사용하며 소개 제목에만 반응형 표시 크기를 추가한다.
- NVIDIA 한국 홈페이지에서 확인한 #76B900 배경·검은 글자·사각 모서리를 주요 버튼에 적용한다. 작은 녹색 글자는 별도의 짙은 색으로 조정한다. 상태를 색상만으로 표현하지 않는다.
- 키보드 초점, 본문 바로가기, 좁은 화면 패널 재배치를 제공한다. 2026-09-25 구현: OS 설정과 무관하게 최초 라이트로 시작하며 상단의 라이트·다크 버튼으로 선택한다. 선택은 이 브라우저에 저장해 새로고침 후 복원하며, 저장이 차단되어도 현재 화면의 전환은 동작한다.
- 일반 UI의 자동 애니메이션은 사용하지 않는다. 사용자 승인된 분자 뷰어는 전체 보기에서 느린 자동 회전, 수동 조작·집중 보기에서 정지, 명시적 재개를 제공하며 동작 줄이기 설정을 존중한다.

## 조사 근거

- [RCSB의 3D·서열 연결 패널](https://www.rcsb.org/docs/sequence-viewers/sequence-annotations-in-3d): 선택한 근거와 구조 위치를 함께 살피는 배치의 참고 사례. 현재 프로토타입은 좌표가 없어 실제 연결을 구현하지 않았다.
- [W3C 대비 기준](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum): 일반 글자 4.5:1, 큰 글자 3:1을 검토 기준으로 사용한다. 현재 전체 접근성 적합성 인증을 의미하지 않는다.

## 표현 경계

실험 사실·계산 결과·미확인을 구분한다. 보류와 실행 실패를 다른 문구로 표시한다. 성공률·치료 효과·임의 순위·추정 완료율을 만들지 않는다. 데이터가 없는 결과에 실제처럼 보이는 수치를 넣지 않는다.

후속 확정: 첫 화면은 넓은 기술 비주얼·굵은 제목·녹색 사각 버튼을 사용하고, 분석 화면은 B안에 같은 스타일을 적용한다. Elements 기준의 초기 시안과 구분하며 [기준 수정 근거](nvidia-design-research.md#기준-수정-nvidia-한국-공식-홈페이지--사용자-확인)를 따른다.

## 라이트·다크 선택 검증 — 2026-09-25

[NVIDIA 한국 홈페이지](https://www.nvidia.com/ko-kr/)를 다시 열어 밝은 본문·검은 제목과 #76B900 배경·검은 글자·0px 모서리의 버튼을 확인했다. 기존 시각 기준을 유지하고 수동 테마를 OS 설정보다 우선한다. 첫 화면을 그리기 전에 저장된 선택을 적용한다. 테마 저장은 분석 데이터나 서버 세션을 보관하지 않는다.

OS light/dark 각각에서 최초 라이트, 양방향 전환, 새로고침 복원, OS 변경 시 선택 유지, 분석·소개·팀·비교·보고 및 320/390px 배치를 Chrome으로 검사했다. 3D canvas와 접촉 부위 선택을 유지하고 구조 파일을 다시 요청하지 않는 것을 확인했다. 분자색과 흰 canvas·범례 배경은 테마와 독립적으로 유지한다. TypeScript·Vite 빌드는 통과했으며 기존 Mol* 큰 청크 경고는 남아 있다.
