# 바이오 에이전트 화면 방향

2026-09-25 사용자 확인: NVIDIA 브랜드 느낌을 유지하면서 바이오와 에이전트 도구의 성격을 추가한다. 첫 화면은 간결하게 하고 설명은 소개로, 팀 소개는 별도 탭으로 분리한다. 자유 대화 기능은 프로젝트 범위가 아니며 질문 입력창은 사용자의 정정에 따라 제거했다.

## 조사와 적용

| 근거 | 확인한 내용 | 우리 화면에 적용한 해석 |
|---|---|---|
| [NVIDIA BioNeMo Agent Toolkit 기술 글](https://developer.nvidia.com/blog/build-an-ai-scientist-for-life-science-discovery-with-nvidia-bionemo-agent-toolkit/) | 과학적 목표에서 도구 선택·입력 준비·실행·결과 검토로 이어지는 작업 흐름 | 에이전트를 채팅 UI와 동일시하지 않는다. 자료 입력→필요한 분석→근거 검토의 기존 구조 유지 |
| [Anthropic Research 소개](https://www.anthropic.com/news/research) | 조사 작업을 에이전트가 수행하고 근거와 함께 결과 전달 | 간결한 진입과 진행·근거 연결을 참고. 우리 서비스에 자유 대화·웹 검색 기능을 추가하는 근거가 아님 |
| [AlphaFold 공식 소개](https://deepmind.google/science/alphafold/) | 단백질과 분자 상호작용을 다루는 생물학 맥락 | 기존 원자 궤도 장식을 단백질 리본·Y자 항체의 추상 개념 그래픽으로 교체. 실제 HER2 구조나 과학적 대응표가 아님 |

위 출처는 기능·과학적 맥락의 참고이며 현재 레이아웃의 사용자 선호 검증이 아니다. BioNeMo의 외부 기능 소개는 우리 서비스에 해당 도구가 연결되었다는 뜻이 아니다.

## 최종 화면

- 분석: 짧은 제목, 모의 예제 3종 선택, 모의 검토 시작, 직접 서열 입력 진입. 선택한 모의 작업은 진행·비교·보고로 이어진다. 자유 질문·대화창·AI 계획 생성 없음.
- 소개: 프로젝트 목적·분석 흐름·해석 한계, 넓은 바이오 개념 그래픽. 팀 프로필은 표시하지 않는다.
- 팀: 정보 없는 프로필 카드 3개와 사용자 확인된 GitHub 링크. 실명·사진·개인별 역할은 추정하지 않는다.

NVIDIA 녹색 주요 행동과 흑백 대비는 유지한다. 첫 화면에는 부드러운 녹색 배경과 일부 둥근 자료 선택 컨테이너를 사용하며, 소개 탭에는 기존 브랜드형 넓은 비주얼을 둔다. Calm Clarity 토큰 체계와 한글 SUIT를 유지한다.

팀원 정보는 후속 제공 예정. GitHub 링크는 `https://github.com/taehyunan-99/nvidia-hackathon`으로 사용자에게 확인했다. 저장소 공개 가시성 변경은 수행하지 않는다.

실제 분석·파일 업로드·3D는 여전히 미연결이다. 직접 서열 입력은 기존 UI 미리보기 범위이며 분석 접수로 표시하지 않는다.
