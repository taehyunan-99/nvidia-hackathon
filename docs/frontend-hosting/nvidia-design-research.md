# NVIDIA 디자인 조사와 적용

조사일: 2026-09-25. 사용자가 NVIDIA의 실제 도구와 연결되는 시각적 인상을 원하며 공식 디자인 지침 조사·적용을 요청했다. 기존 Calm Clarity 기반의 화면 구조와 여백을 유지하고 프로젝트 테마만 조정한다.

Elements 공식 문서의 테마 페이지를 실제 브라우저에서 확인했다. Build 사이트는 검색 자료만 확인했으므로 해당 제품을 직접 시각 분석한 근거로 삼지 않는다. 오래된 2012년·파트너용 PDF를 현행 제품 UI 규정으로 사용하지 않는다. Elements의 토큰은 전체 NVIDIA 제품에 공통으로 강제되는 브랜드 규정이라고 단정하지 않는다.

## 해석과 프로젝트 선택

**공식 자료에서 관찰한 것**은 녹색 강조/검은 버튼 글자, Inter, 계층별 중립색, 선택·상태 구분이다. **우리 프로젝트의 시각적 선택**은 밝은 본문과 어두운 소개 그래픽의 대비, 얇은 그리드와 녹색 입체 그래픽, 작은 모서리 반경이다. 그리드·그래픽을 NVIDIA 필수 지침으로 표현하지 않는다.

- 개인 Calm Clarity 스킬과 복사한 기본 토큰은 유지한다. [별도 프로젝트 테마](../../frontend/src/nvidia-theme.css)가 의미 토큰을 재정의한다.
- 영문은 Inter, 한글은 SUIT로 조합한다. 기존 4px 간격과 본문 크기를 유지한다. 둥근 컨트롤을 조금 단정하게 조정하되 화면 전체를 고밀도 콘솔로 바꾸지 않는다.
- 작은 녹색 글자는 별도의 짙은 녹색을 사용한다. 녹색 CTA는 검은 글자를 사용하며 흰 글자와 섞지 않는다.
- 소개용 추상 그래픽은 실제 HER2 구조가 아님을 계속 표시한다. NVIDIA 도구가 실제로 연결되었다는 문구나 배지는 붙이지 않는다.
- 진행 상태·보류·실패의 의미와 9개 모의 자료는 변경하지 않는다.

## 검증

타입 검사·프로덕션 빌드 통과. 브라우저에서 밝은/어두운 테마의 CTA 대비를 각각 6.08:1로 측정했다. 데스크톱·390px 모바일 배치와 입력→진행→비교→보고의 모의 탐색을 확인했다. 실제 분석·NVIDIA API 연결·전체 접근성 인증·공식 브랜드 승인과는 구분한다.

## 기준 수정: NVIDIA 한국 공식 홈페이지 — 사용자 확인

2026-09-25 사용자가 https://www.nvidia.com/ko-kr/ 를 원하는 인상의 기준으로 명시했다. 초기 Elements 기반 해석은 사용자가 원한 브랜드 홈페이지의 인상과 달랐다. 위 내용은 초기 조사 이력이고, 현재 시각 기준은 이 절이다.

1440×1000 브라우저에서 한국 홈페이지를 직접 열어 쿠키 선택창을 닫은 화면과 스타일을 확인했다. 관찰한 CTA 배경은 `rgb(118,185,0)` (#76B900), 글자는 18px·700, 모서리는 0px이었다. 보이는 대표 배너 제목은 36px·700·45px 행간, 글꼴 선언은 NVIDIA-APAC, Source-Han-Sans-KR, Arial, Helvetica, sans-serif였다. 이는 관찰 시점의 요소 값이며 모든 페이지에 강제되는 규칙은 아니다.

적용: 녹색을 #76B900으로 조정하고 검은 글자의 사각 CTA, 굵은 제목, 낮은 헤더, 검은 단계 탐색 바, 가로로 펼친 기술 비주얼을 사용한다. 둥근 독립 그래픽 카드를 없애 소개 영역과 비주얼을 하나의 넓은 배경으로 통합했다. 홈페이지 자체는 밝은 배너도 제공하므로 ‘NVIDIA는 항상 검정 배경’이라고 해석하지 않는다. 우리 시안의 어두운 소개 배경과 추상 그래픽은 프로젝트에 맞춘 선택이다.

NVIDIA 전용 글꼴·로고·배너를 복제하지 않았다. 한글 SUIT와 영문 Arial을 대체 조합으로 사용하며 공식 글꼴과 동일하다고 주장하지 않는다. Elements는 필요할 때 상호작용 참고로만 사용하고, 현재 화면을 Elements 준수 구현이라고 표현하지 않는다. 분석 화면은 B안의 정보·모의 상태를 유지하며 색상·제목·버튼·패널 스타일만 통일한다.
