# 출처와 선별 기록 작업 가이드

## 1. WHAT — 역할

자료의 확인 범위와 새 저장소에 남긴 이유를 추적한다.

## 2. CONTENTS — 파일과 형식

- `sources-and-method.md` — 출처와 해석·검증 범위
- `document-selection.md` — 이관·편집·제외 목록

형식: Markdown 중심. 애플리케이션 기술 스택은 미확정.

## 3. HOW — 수정 방법

출처, 확인일, 변경한 범위, 검증 공백을 기록한다. 이동 시 상대 링크를 갱신한다.

## 4. ⛔ HOW NOT — 주의할 함정

- 새 저장 날짜를 외부 사실의 재검증 날짜로 취급하지 않는다 — 이관과 사실 확인은 다른 작업이다.

## 5. WHERE — 의존성과 경계

docs의 각 문서에서 참조하며 원본 자료는 기존 nvidia 저장소에 그대로 보존된다.

## 6. WHY — 배경

개인 조사 전체를 복제하지 않고 필요한 기록만 옮겼기 때문에 선별 근거를 별도로 남긴다.

## 7. COMMANDS — 검증 명령

저장소 루트에서 `git diff --check`로 공백 오류를 확인하고 변경 문서의 상대 링크·import 대상을 직접 확인한다. 앱 빌드·테스트 명령은 아직 없다.
